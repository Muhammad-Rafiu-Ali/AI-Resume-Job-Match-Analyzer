Project Overview

Helping job seekers understand resume-job fit before applying

Many applicants submit resumes without knowing how well their CV matches the job description. This project solves that problem by combining text similarity, keyword matching, skills detection, and ATS-style scoring in one simple web application.

The analyzer extracts resume text from PDF, DOCX, or TXT files, compares it with the job description, highlights missing job keywords, checks resume sections, recommends suitable job roles, and generates a downloadable report and cover letter.

Analysis Logic

The project uses explainable NLP and rule-based scoring instead of a hidden black-box model.

TF-IDF

Converts resume and job description text into weighted keyword vectors.

Cosine Similarity

Calculates how closely the resume text matches the job description.

Keyword Matching

Extracts job keywords and identifies which ones are present or missing in the resume.

ATS Rules

Scores contact, skills, education, experience, formatting, length, keywords, and headings.

Frequently Asked Questions

Important notes about how the analyzer works.

Does it work with every resume?

It works best with text-based PDF, DOCX, and TXT resumes. Image-based or heavily designed PDFs may have limited text extraction quality.

Why can candidate name extraction differ?

Some PDFs store text in unusual order. The app uses strict name detection and avoids showing wrong names when the extracted text is unclear.

Is the ATS score a real company ATS score?

No. It is an explainable scoring model designed for learning and portfolio demonstration. It approximates common ATS-style checks.

Can this be improved further?

Yes. Future versions can add Gemini/OpenAI integration, PDF report export, resume rewriting, and advanced job recommendation models.
